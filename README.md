# 달밥 장부 (월정액 선불 식사 관리)

## 사장님 사용법
1. **실행**: Windows는 `Dalbap.exe`, 맥은 `Dalbap.app`을 더블클릭.
   - 맥 첫 실행: "확인되지 않은 개발자" 경고 → 앱을 **오른쪽 클릭 → 열기 → 열기** (한 번만).
   - 윈도우 첫 실행: "Windows의 PC 보호" → **추가 정보 → 실행**.
   - 방화벽 허용 창이 뜨면 **개인 네트워크 허용**을 눌러 주세요 (손님 휴대폰 접속용).
2. **새 손님** → 이름 입력 → 바로 **충전**.
3. **충전** (v1.1.0~): 손님 선택 → 충전 버튼 → 금액 입력 → **서명 방법 선택**:
   - **이 PC에서 서명**: 손님이 마우스/터치로 서명 → 확인 → 충전 완료.
   - **아이패드로 서명 받기**: QR 코드 표시 → 사장님 로그인된 아이패드/휴대폰에서 "서명 요청" 표시 → 손님이 펜/손가락으로 서명 → 확인 → PC에서 충전 완료.
   - 서명 없이는 충전되지 않습니다. 서명은 `signatures/연도/월/` 폴더에 PNG로 저장됩니다.
   - 거래 테이블의 ✍ 표시로 서명이 있는 충전을 확인할 수 있습니다.
4. 식사 때: 손님 검색 → 선택 → **🍚 식사 차감** (기본 1식 가격, ⚙에서 변경).
   잔액이 모자라면 경고가 뜨고, "예"를 눌러야만 마이너스로 차감됩니다.
5. 실수했으면: 거래 선택 → **거래 취소**. 지워지지 않고 반대 거래로 남습니다.
6. 왼쪽 달력: 날짜마다 충전(+)/차감(-) 합계(천원 단위), 날짜를 누르면 그날 누가 충전·식사했는지 표시.
7. **📱 손님 QR 코드**: 손님이 휴대폰 카메라로 찍으면 본인 잔액·내역만 보입니다.
   (매장 와이파이 연결 + 이 프로그램이 켜져 있을 때만). 링크가 샜으면 "링크 새로 만들기".

8. **영수증 (PC)**: 거래를 선택하고 "선택 거래에 영수증 첨부", 또는 "영수증 → 사진 첨부"로 그 날짜에 따로 등록.
   충전할 때 이체 내역 사진을 바로 붙일 수도 있습니다. 가운데 "영수증" 탭에서 미리보기, 두 번 누르면 원본 보기.
   달력 칸 오른쪽 위 🧾숫자 = 그날 영수증 장수.
   - **수정**: 영수증 선택 → "수정" → 금액·메모·손님·연결 거래 변경 → 저장.
   - **삭제**: 영수증 선택 → "삭제" → 확인. 사진은 `receipts/_trash/`(휴지통)로 옮겨질 뿐 지워지지 않습니다.
   - **복원**: "휴지통" → 영수증 선택 → "선택한 영수증 복원".
9. **영수증 (아이패드·휴대폰)**: "설정 → 사장님 PIN"에서 숫자 4~8자리 PIN을 정하고 → "영수증 → 휴대폰 등록" QR을 사장님 기기로 찍기
   → PIN 입력 → **📷 영수증 촬영** → (금액·손님·메모는 선택) → "PC로 보내기". 사진은 PC에 저장됩니다.
   - 사장님 전용 QR은 손님에게 보여주지 마세요. PIN 5번 틀리면 5분 잠깁니다. 의심되면 "링크 새로 만들기"/PIN 변경.
   - 휴대폰 페이지 아래 "최근 영수증" 10장 목록에서 "삭제"도 됩니다 (확인 후 휴지통으로, PC에서 복원).
   - 손님 페이지에서는 영수증을 절대 볼 수 없습니다. 사진은 최대 10MB, JPG/PNG/WEBP/GIF만 됩니다.

## 데이터
- 위치: 내 폴더(홈) 아래 `달밥데이터` (`customers.json`, `settings.json`, `tx/2026-10.json`처럼 월별 거래).
- 영수증 사진은 **이 PC에만** 저장됩니다: `달밥데이터/receipts/연도/월/` (삭제한 것은 `receipts/_trash/`), 목록은 `receipts/receipts.json`.
- 서명 이미지: `달밥데이터/signatures/연도/월/` 폴더에 PNG로 저장됩니다.
- 매일 처음 켤 때 `달밥데이터/backups/날짜` 에 자동 백업 (60일 보관). 영수증 **사진은 용량 때문에 자동 백업에서 제외**(목록만 백업)되니 `receipts` 폴더는 가끔 직접 복사해 두세요. 이 폴더를 USB/클라우드에 가끔 복사해 두세요.
- 복구: 프로그램 종료 → 원하는 날짜 백업 폴더 내용을 `달밥데이터`에 덮어쓰기.

## 개발자용
```bash
python -m venv .venv && . .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements-dev.txt
python main.py               # 실행
python -m pytest -q          # 테스트
python main.py --selftest    # 화면 없이 점검
pyinstaller --noconfirm --onefile --windowed --name Dalbap --add-data "dalbap/fonts:dalbap/fonts" main.py   # 현재 OS용 실행파일 (dist/)
```
- Windows/맥 실행파일: GitHub에 올리면 `.github/workflows/build.yml`이 자동 빌드 →
  Actions 탭의 Artifacts에서 `Dalbap-Windows`(exe zip), `Dalbap-macOS`(app zip) 다운로드.
- 손님 웹 포트: 8765 (`settings.json`의 `port`로 변경).

## 글꼴
- 앱에 **Pretendard** 글꼴(SIL Open Font License 1.1, `dalbap/fonts/Pretendard-LICENSE.txt`)이 들어 있어 윈도우·맥에서 같은 모양으로 보입니다.
  PC에 설치하지 않고 프로그램이 켜져 있는 동안만 사용합니다. 불러오기에 실패하면 맑은 고딕/Apple SD 고딕 Neo로 표시됩니다.
